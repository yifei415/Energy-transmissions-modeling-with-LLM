# IoT Energy & Transmission Modeling Project


## 1. General Context and Motivation


This project is motivated by a smart nursing home deployment scenario. The environment consists of multiple wireless IoT devices communicating via protocols such as Wi-Fi or ZigBee.

A representative use case is fall detection: a nurse may express the intent *“Make sure that the patient does not fall wherever she goes.”*  To satisfy this intent, the system must dynamically activate sensors along the patient’s path. However, IoT devices are energy- and transmission-constrained. Continuously querying all devices would rapidly drain batteries and overload the network.

The goal of this sub-project is to provide accurate energy consumption and transmission models, enabling energy-aware orchestration and sustainable IoT system design.

---

## 2. Overall Architecture of the Proposed Approach

The proposed system is designed to support the Plan Validation Agent within the LLMThings architecture. 

- **Input:** Execution plan generated by the orchestration agent (specifies devices to activate, modules, durations).  
- **Processing:** Energy consumption and transmission modeling for each device in the plan.  
- **Output:** Structured JSON report containing:  
  - Per-device energy consumption estimates  
  - Per-device transmission time estimates  
  - Aggregated indicators (e.g., total energy, maximum transmission time)  

These results are provided to the Plan Validation Agent to enable energy-aware and transmission-aware plan validation.
